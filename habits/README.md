# Атомные привычки

Личный трекер полезных и вредных привычек по принципам книги
«Atomic Habits» Джеймса Клира. Статическое веб-приложение (PWA) —
работает в браузере на ПК, iPhone и MacBook, без сервера и регистрации.

## Возможности

- **Осваивайте полезные привычки** через четыре закона: сделайте
  привычку очевидной (время, место, связка с существующей рутиной),
  привлекательной (награда), лёгкой (версия на 2 минуты) и приятной
  (отметка выполнения).
- **Бросайте вредные привычки**, переворачивая законы: уберите триггер,
  назовите настоящую цену, добавьте препятствие.
- **Идентичность**: у каждой привычки можно указать, кем вы становитесь
  благодаря ей — ключевая идея книги про изменение личности, а не
  только результата.
- Ежедневный чек-лист, серии (streak), календарь-«тепловая карта» по
  каждой привычке, предупреждение «не пропускай дважды».
- Работает офлайн (service worker), устанавливается на домашний экран
  iPhone/iPad и в Dock на Mac как отдельное приложение.
- Все данные хранятся **только в этом браузере** (localStorage). Экспорт
  и импорт JSON-файлом позволяют перенести историю на другое устройство.

## Как открыть

Просто откройте `index.html` в браузере, либо разместите папку `habits/`
на любом статическом хостинге (например, GitHub Pages для этого
репозитория — `https://<user>.github.io/Bushrut/habits/`).

### Установка на iPhone

Safari → кнопка «Поделиться» → «На экран “Домой”».

### Установка на Mac (Safari) или в Chrome/Edge на ПК

В адресной строке — значок установки приложения, либо через меню
браузера «Установить сайт как приложение».

## Технологии

Ванильные HTML/CSS/JS, без сборки и зависимостей. Все данные и логика —
в трёх файлах: `index.html`, `styles.css`, `app.js`.
